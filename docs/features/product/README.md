# Product features

- [Local Ollama suite manager](./ollama-suite-manager.md) — a local-only
  desktop suite for documented runtime health, installed/running model facts,
  model details and fit evidence, bounded pull batches, streamed local chat,
  capability-gated image attachments, and allowlisted harness profiles with
  preflight and rollback. The documented local API does not expose an exhaustive
  official catalog; the app records that conflict visibly and refuses a remote
  or credentialed workaround.
- [File converter foundation](./file-converter.md) — the explicit current gap;
  no converter UI or conversion process is claimed until the bounded local
  workflow is implemented.
