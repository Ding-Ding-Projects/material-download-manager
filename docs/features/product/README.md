# Product features

- [Local Ollama suite manager](./ollama-suite-manager.md) — a bounded desktop
  foundation for recording credential-free loopback providers, refreshing the
  installed-model inventory through Ollama's documented local API, and moving
  redacted metadata without claiming the larger catalog, chat, attachment, or
  harness features that are not yet shipped.
- [File converter foundation](./file-converter.md) — the explicit current gap;
  no converter UI or conversion process is claimed until the bounded local
  workflow is implemented.
